First version of Popa, a small and private application launcher for Windows 11.

- Popup menu with your programs at the mouse pointer: **Win+Z** (configurable) or a click on the tray icon.
- Submenus, separators, icons from 16 to 48 px, light and dark themes.
- Editor with drag and drop (inside the tree and from Explorer), icon picker and automatic saving.
- Import of menus from XML configuration files.
- Start with Windows, update check through GitHub Releases.
- One portable file, no telemetry. English and Spanish interface.

Primera versión de Popa, un lanzador de aplicaciones chico y privado para Windows 11.

- Menú emergente con tus programas en el puntero del mouse: **Win+Z** (configurable) o un clic en el icono de la bandeja.
- Submenús, separadores, iconos de 16 a 48 px, tema claro y oscuro.
- Editor con arrastrar y soltar (dentro del árbol y desde el Explorador), selector de iconos y guardado automático.
- Importación de menús desde archivos de configuración XML.
- Inicio con Windows y búsqueda de actualizaciones en GitHub Releases.
- Un solo archivo portable, sin telemetría. Interfaz en inglés y español.
